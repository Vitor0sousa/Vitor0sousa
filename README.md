## 📌 Projetos em destaque

### 🛍️ [ERP Gestão — Sistema de Gestão Comercial](https://github.com/Vitor0sousa/erp-gestao)

Aplicação web desenvolvida em **Angular e Supabase**, voltada à organização de produtos, pedidos e estoque, com integração à API do Mercado Livre.

- Sincronização de anúncios e vendas por **APIs e webhooks**.
- Controle de produtos simples e kits, custos e indicadores financeiros.
- Ecossistema com servidor **MCP** independente para consultas por assistentes de IA, utilizando autenticação **OAuth 2.0** e acesso restrito aos dados.

> 🔒 **Confidencialidade:** o sistema atende uma operação comercial real. Dados de clientes e indicadores internos não são expostos aqui; eventuais demonstrações públicas devem utilizar dados fictícios.

### 🧠 [Wenity AI — Análise Inteligente de Currículos](https://github.com/Vitor0sousa/ia_wenity)

Projeto colaborativo que utiliza inteligência artificial para analisar currículos com base em critérios de vagas e gerar feedback estruturado. Minha atuação no projeto foi voltada ao **backend e às APIs REST**, conforme documentação do repositório.

### 🎙️ [Jarvis — Assistente de Voz com IA](https://github.com/Vitor0sousa/Jarvis)

Protótipo em **Python** com reconhecimento de voz em português, síntese de fala e integração com um modelo de linguagem por API.
